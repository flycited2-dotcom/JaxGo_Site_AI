# JaxGo_Site_AI

Исходники сайта [JAXGO](https://jaxgo.ru/) и опубликованного раздела статей.

## Локальный запуск

Нужен Node.js 20 или новее.

```sh
npm start
npm test
```

По умолчанию сайт доступен по адресу `http://127.0.0.1:3000`. Для проверки формы используются тестовые каналы. Настройки рабочей доставки хранятся в окружении хостинга, пример переменных приведён в `.env.example`.

## Статьи

Каталог доступен по адресу `/articles/`, материалы — по адресу `/articles/<slug>/`. Опубликованный срез сайта находится в `public/`. Генератор и издатель находятся в `scripts/seo/`.

Для пересборки очереди оператору нужны закрытый набор исходников `SEO/articles/` и план публикаций. Установите зависимости из `scripts/seo/requirements.txt` и передайте план через `--plan`:

```sh
python scripts/seo/build_publication.py --plan /path/to/plan.json
```
